# v0.1.0 — Linux x86_64 preview

自作の 2D 自律走行シミュレーション向け描画バックエンドの初回プレビューです。

## 含まれるもの

- 地図・経路・ロボット・LiDAR を描画する Rust サンプルと、グラフを描画する Rust サンプル
- C ABI 共有ライブラリ、C ヘッダー、C++20 Visualizer アダプター、CMake import 設定、C++ サンプル
- Apache-2.0 のプロジェクトライセンス、同梱フォントと依存クレートのライセンス文書

## 動作条件

Linux x86_64 と Vulkan ローダー・対応アダプター・ドライバーが必要です。ウィンドウ表示は X11 を使用します。実行時に Rust ツールチェーンは必要ありません。詳しい使い方はリポジトリの README を参照してください。

`ad-visualization-v0.1.0-linux-x86_64.tar.gz.sha256` で tarball の SHA-256 を確認できます。展開後は `SHA256SUMS` で各ファイルを確認できます。
